## 1. 现在的问题（2026-11-12 查代码确认）

| 问题 | 现状 |
|---|---|
| 没有图 | App 里除了图标和启动图之外没有任何图片；内容格式里也没有图片字段 |
| 讲解靠后、像说明书 | 每课有 `intro`（一句话）和 1–3 条 `notes`（讲解），但讲解排在"学完所有词 + 对话"之后，纯文字 |
| 题型单调 | 只有 4 种四选一（看词选意思、听音选意思、看意思选词、听音选词）+ 跟读打分；没有填空、排序组句、配对、认读 |
| 学完才考 | 先连续学 4–7 个词，再集中做题；零基础的人记不住 |
| 测验不像考试 | 单元测验和练习课也只是上面那几种四选一；没有阶段考试 |
| 地图像清单 | 课程地图是一长串灰色列表，看不出走到哪、还剩多少 |
| 反馈弱 | 答对 / 答错只变颜色，不解释为什么 |

**已有的底子都保留**：约 1.4 万词条、对话、讲解、读物（B 阶段起每单元 1–2 篇，带阅读题）、4 万段配音、FSRS 复习、XP 和连续天数、分级测试、AI 口语老师。**课号和词条 id 不改，进度数据格式不变。**

## 2. 参考了谁、取什么、不取什么

| 软件 | 取 | 不取 |
|---|---|---|
| **Duolingo** | 路线式地图；一屏一个小步骤；学一点马上考一点；答完即时反馈；连续天数、每日目标、XP；错题在课尾再出一次 | 大量重复的低难度翻译题；"心"扣完就不能学（容易劝退，见 §8）；排行榜、好友 |
| **HelloChinese** | 声调图示和声调练习；拼音 → 汉字的过渡（到一定阶段默认隐藏拼音）；汉字认读题 | 手写描红（第一版不做） |
| **Super Chinese** | 每课开头讲清"这课学什么"；对话为核心；按 HSK 分级考试型练习 | 视频课 |
| **LingoDeer** | 讲解卡（语法小结）在练习之前、可随时回看；讲解里用母语对比 | 长篇语法文章 |
| **考试（HSK / JLPT / TOPIK / TOEIC 风格）** | 填空、阅读理解、分项得分；考试时隐藏拼音 / 罗马字 | 计时压力（第一版不计时） |

总的原则：**比 Duolingo 更重"讲清楚"和"认字、填空、阅读"**，游戏化只做能帮坚持的那几样（连续天数、每日目标、单元奖励），不做竞争类的。

## 3. 一节正课的新流程

草图 ①②③④。以 zh-A1-03《สบายดีไหม》（6 个词、3 句对话、3 条讲解）为例，约 25 个小步骤、6–8 分钟：

1. **讲解卡**（草图 ①）：这课学什么 + 最关键的 1–2 条讲解，配图示（声调走势、句型公式如"句子 + 吗 = ไหม"），例子点了能听。其余讲解放在对应的词后面，或课尾"小结"里。课中可随时点 💡 回看。
2. **学词卡**（草图 ②）：图片（有图的词）+ 文字 + 读音 + 泰语注音 + 意思，自动播放读音，可慢放、可跟读。
3. **学完一个词马上考一题**：认意思或听音选词，二选一 / 三选一起步，越往后选项越多。
4. **每 2–3 个词一组配对**：词和意思（或词和读音）连线，5 对以内。
5. **对话**：逐句出现、逐句播放，可点每句看译文。
6. **用对话出题**：填空 2–3 题（草图 ③）、排序组句 1–2 题（草图 ④）、认字 1–2 题。
7. **跟读**：挑 1–2 句对话跟读打分（有 Azure 密钥时；没有就跳过）。
8. **错题重做**：本课答错的题在最后再出一次，答对才算过。
9. **小结**：本课学会的词（带图）、讲解要点、得分和 XP。

## 4. 新题型（都由引擎从现有内容自动出，不用重写课）

| 题型 | 怎么出 | 适用 | 草图 |
|---|---|---|---|
| 认意思（已有） | 看词选泰语意思 | 全部 | — |
| 听音选词（已有） | 听读音选文字 | 全部 | — |
| **配对** | 本课 / 本单元 5 个词：文字 ↔ 意思，或文字 ↔ 读音 | 全部 | — |
| **认字（看字选读音 / 看读音选字）** | 选项从同课 / 同单元读音或字形相近的词里挑 | zh（汉字 ↔ 拼音）、ja（汉字 / 假名 ↔ 罗马字）、ko（韩文 ↔ 罗马字）、en（单词 ↔ 正确拼写，干扰项用相近拼写） | — |
| **填空** | 对话或读物里含已学词的句子，挖掉那个词，四个词块选一；干扰项优先用同课的词和同类虚词 | 全部 | ③ |
| **排序组句** | 把对话里的一句拆成词块按顺序点出来，加 1 个干扰词块；给泰语译文和读音按钮 | 全部 | ④ |
| **听音组句** | 只播放读音，不给译文，排出句子 | B 阶段起 | — |
| **阅读理解（加强）** | 读物原有的题目 + 引擎出的"读文填空"；考试里拼音默认隐藏 | 有读物的单元（T22 给 A 阶段补读物） | ⑥ |
| 跟读（已有） | 发音打分 | 全部（有密钥时） | — |

**拆词块的办法**：中文、日文句子没有空格，引擎按"本课及以前学过的词条文字"从左到右最长匹配切分，剩下的单字自成词块；英文、韩文按空格切。只挑切出来不超过 7 块、而且至少一半是已学词的句子出题，切不好的句子不出排序题。

**读音显示**：A、B 阶段默认显示拼音 / 罗马字；从 C 阶段起默认隐藏，可点开（草图 ④ 底部的提示、⑥ 的开关）；考试里默认隐藏。

**题量**：一节正课约 12–16 题（现在约 10–14 题），新增的题主要是填空、排序、认字。按店主"量不是全参考"的意思，不照搬 Duolingo 一课 20 多道题的密度。

## 5. 练习课、单元测验、阶段考试

| | 现在 | 改成 |
|---|---|---|
| **练习课**（每 2 课一节） | 已学词的四选一 | 偏认字和填空：配对 1、认字 4、填空 4、排序 2、听音组句 1（约 12 题），优先出 FSRS 快到期的词 |
| **单元测验**（每单元一次，70 分过） | 四选一 | **考试卷**，约 20 题：听力 5、认字 5、填空 5、排序 3、阅读或对话理解 2；显示分项得分；错题进复习 |
| **阶段考试**（新增，每个阶段末一次） | 无 | 约 40 题，四部分：听力 10、认字 10、阅读 10（用本阶段读物和对话）、填空 10；草图 ⑥；拼音默认隐藏；分项得分 + 总分；过线给阶段徽章 |

阶段考试的组卷规则参考该阶段对应的考试（`course.json` 的 `exam` 字段：zh 对应 HSK，ja 对应 JLPT，ko 对应 TOPIK，en 对应 CEFR），只用本阶段学过的内容。

## 6. 课程地图和游戏化

草图 ⑤。

- **路线**：每个单元一条弯曲路线，圆形节点：正课 ▶、练习 🔁、读物 📖、单元测验 🏆；已完成金色、当前绿色并带"เริ่ม"提示、未解锁灰色。阶段末多一个"阶段考试"节点。
- **单元横幅**：单元名、进度（4 / 10）、这单元学什么、一张主题图。
- **顶部**：课程、连续天数 🔥、XP ⭐（"心"按 §8 决定）。
- **每日目标**：10 / 20 / 30 / 50 XP 四档，在设置里选，首页显示圆环进度。
- **奖励**：完成单元、通过阶段考试有一个简单动画和徽章；不做商店、宝石、排行榜。
- **底栏**：首页（地图）、复习、AI 老师、我的。

## 7. 配图

- **只给能画的词配图**：物品、食物、动物、动作、地点、人物、天气、交通等；抽象词（因为、已经、的）不硬配，靠例句和讲解。能配图的大约占词条的三到四成，T19 先做工具统计准确数量。
- **同一个意思四门课共用一张图**（中文"苹果"、英语 apple、日语 りんご、韩语 사과 是同一张）。词条加一个可选的"概念"字段，词条 id 不变。
- **两种来源（店主在 T16 选）**：
  - **A. 免费图标库（建议先用）**：例如 Microsoft Fluent Emoji（MIT 许可，可商用）或 OpenMoji（CC BY-SA，要署名）。风格统一、不花钱、马上能做，常见的具体词基本都有。缺点是像表情符号，不够"插画"。草图 ② 的 🙏 就是这种效果。
  - **B. AI 生成插画**：风格可定制、更好看；要店主开通图片生成服务（密钥只填进环境设置）并承担费用，每张要人工抽查，生成和审图要几天。
  - 可以先 A 后 B：先用图标库上线，以后按需把常用词换成插画，不影响别的功能。
- 单元横幅的主题图用同一套来源。

## 9. 对现有东西的影响

- **内容**：已有课一律不重写。T22 只给 A、B 阶段改写讲解（一句结论 + 2 个例句 + 泰语对比）、A 阶段每单元加 1 篇短读物（新 `-r` 课号）、加汉字部首 / 假名 / 韩文字母的认读讲解；新句子补配音。
- **进度和复习**：格式不变，旧进度照常能用；练习课、测验是引擎现生成的，换题型不影响存档。阶段考试是新节点，旧用户的已完成状态不受影响。
- **e2e**：课程地图、上课页面、完成页的检查要按新界面改写（T18、T20、T23 各自改）。
- **其他母语**：界面文字的 key 照旧以 `content/l1/th/ui.json` 为准；讲解卡、配图都不写死语言。
