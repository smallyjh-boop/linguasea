## 0. 核心原则

1. **先开口**：每学一个短语，第一件事是听、然后自己说出来并马上得到鼓励性的打分（草图 ⑦）；每课最后用自己的嘴把对话"演"一遍（草图 ⑧）。说出来了才有信心。
2. **前期只用短语**：A 阶段说的都是 1–4 个词的短句（"你好""谢谢""你好吗？""我也很好"），不超过约 8 个音节；B 阶段放宽到约 12 个音节；长句和段落留到 C 阶段以后。
3. **有趣**：有固定的角色（น้ำ / 小南、王明……）和场景，答题有连击、星星、音效和小动画，一课 5–8 分钟就能拿到"我会说了"的成就感。
4. **讲清楚，但只讲一点**：每次只讲一个点，配图示和泰语对比，放在要用到的地方。
5. **认字、填空、阅读逐步加重**：A 阶段以说和听为主；从 B 阶段起认字和填空变多；C 阶段起默认隐藏拼音，阅读和考试型题目成为重点。

## 3. 一节正课的新流程（A 阶段）

以 zh-A1-03《สบายดีไหม》（你好吗？/ 我 / 很 / 好 / 也 / 你呢？，3 句对话）为例，约 20–25 个小步骤，5–8 分钟：

1. **目标卡**："学完这课你能说：你好吗？我很好。你呢？"，播放一遍这段对话，配场景图（咖啡店里两个老朋友碰面）。
2. **听 → 说，一个短语一个短语来**（草图 ②⑦）：
   - 学词卡：图（有图的词）+ 文字 + 读音 + 泰语注音 + 意思，自动播放。
   - 马上跟读：按住 🎤 说一遍，逐字标颜色（绿 = 好、黄 = 差一点、红 = 再来），给 1–4 颗星，可以回放自己的声音和标准音对比，可以慢放。**没过也能继续**，只是没星星；鼓励语气（"เก่งมาก!"），只指出一个最该改的地方。
   - 连续说过有连击提示（🔥 พูดผ่านติดกัน 3 ครั้ง）和音效。
3. **一句话讲解**（草图 ①）：在第一次碰到"吗"时插一张小卡："句子 + 吗 = ไหม"，例子点了能听。声调卡放在 zh-A1-01 第一次跟读之前。每课最多 2 张。
4. **小练习穿插**：每 2 个短语后一道认意思或听音选词，二选一 / 三选一起步。
5. **把短语连成句子说**：读对话里的一句（短的）——先听、再跟读。
6. **角色扮演**（草图 ⑧）：用户演 น้ำ，App 演王明；轮到你时显示泰语提示（"บอกว่าสบายดี แล้วถามกลับ"），说出来就打分；卡住可以点 💡 看原句。演完给总评星级。
7. **认字和填空（A 阶段少量）**：1–2 道（草图 ③④）。
8. **错题重做** → **小结**：本课学会说的句子（可以再点着听自己的录音）、星星、XP。

### 不能说话的时候

- **"现在不方便说话"**：所有口语题跳过 15 分钟（Duolingo 也这样），改成听音选词，不扣分。
- **没有麦克风权限 / 没配发音打分的服务器**：仍然让用户跟读，录下来回放和标准音对比、自己点"说对了 / 再练练"。
- 网页版和手机版都适用。

## 4. 题型（都由引擎从现有内容自动出，不用重写课）

| 题型 | 怎么出 | 阶段 | 草图 |
|---|---|---|---|
| **跟读短语**（加强） | 每个新词 / 短语学完马上跟读；逐字颜色、星级、回放 | 全部，A 最多 | ⑦ |
| **跟读句子** | 对话里的句子，A 阶段只挑 ≤ 约 8 个音节的 | 全部 | — |
| **角色扮演** | 用本课对话：用户演一方，按泰语提示说出自己的台词，按原句打分 | 全部 | ⑧ |
| **听后回答**（B 起） | 听一句问话（"你叫什么名字？"），说出回答；按本课对话里的答句打分 | B 起 | — |
| 认意思 / 听音选词（已有） | 四选一，A 阶段先二选一 / 三选一 | 全部 | — |
| **配对** | 5 个词：文字 ↔ 意思，或文字 ↔ 读音 | 全部 | — |
| **认字（看字选读音 / 看读音选字）** | zh 汉字 ↔ 拼音；ja 汉字 / 假名 ↔ 罗马字；ko 韩文 ↔ 罗马字；en 单词 ↔ 正确拼写 | 全部，B 起加重 | — |
| **填空** | 对话 / 读物句子挖掉一个已学词，四个词块选一 | 全部，B 起加重 | ③ |
| **排序组句** | 句子拆成词块按顺序点，加 1 个干扰词；A 阶段 ≤ 4 块 | 全部 | ④ |
| **听音组句** | 只听不看译文，排出句子 | B 起 | — |
| **阅读理解**（加强） | 读物原有题目 + 读文填空；考试里拼音默认隐藏 | 有读物的单元 | ⑥ |

**拆词块**：中文、日文按"已学词条"从左到右最长匹配切分，剩下的单字自成词块；英文、韩文按空格切。切不好的句子不出排序题。

**句子长短的标准**（引擎按阶段挑句子，内容里已有的长句只是不拿来练说）：A ≤ 约 8 个音节；B ≤ 约 12；C 起不限。

**读音显示**：A、B 默认显示拼音 / 罗马字；C 起默认隐藏、可点开；考试里默认隐藏。

## 5. 各阶段的比重

| 阶段 | 说（跟读、角色扮演、听后回答） | 听 | 认字 / 填空 / 排序 | 阅读 |
|---|---|---|---|---|
| A | 约 50% | 约 25% | 约 25% | —（T22 补短读物后少量） |
| B | 约 40% | 约 25% | 约 30% | 约 5% |
| C 起 | 约 30% | 约 20% | 约 30% | 约 20% |

一节正课约 14–18 个答题步骤（现在约 10–14 题），新增的主要是跟读和角色扮演。

| | 现在 | 改成 |
|---|---|---|
| **练习课**（每 2 课一节） | 已学词的四选一 | 先"说一遍"已学的短语（跟读 4–6 句，优先 FSRS 快到期的），再配对、认字、填空，约 12 步 |
| **单元测验**（每单元一次，70 分过） | 四选一 | **口语 + 考试卷**：角色扮演一段（本单元的情景），再加听力、认字、填空、排序、阅读，约 20 题，分项得分 |
| **阶段考试**（新增，每阶段末一次） | 无 | 约 40 题：口语 5、听力 10、认字 10、阅读 / 填空 15；草图 ⑥；拼音默认隐藏；过线给阶段徽章 |
| **AI 口语老师**（已有） | 单元里的一个入口 | 单元测验后推荐"和老师自由聊一聊"作为奖励关卡 |

## 6. 有趣：角色、场景、反馈、地图

- **固定角色**：内容里已经有 น้ำ（小南，泰国学生）和王明等人物；给每个角色一个头像（草图用表情占位），对话、角色扮演、单元横幅都用他们。其他三门课用各自课里的人物。
- **场景**：每课目标卡和角色扮演开头有一句场景（"☕ 在咖啡店碰到很久没见的老朋友……"），从现有对话的情境来，母语层写一句即可（T22）。
- **即时反馈**：答对 / 说对有音效和小动画、星星、连击；答错只说一句为什么，不打击（草图 ③⑦）。
- **路线式地图**（草图 ⑤）：一个单元一条弯曲路线，圆形节点：正课 ▶、练习 🔁、读物 📖、单元测验 🏆；已完成金色、当前绿色。单元横幅写"这单元学完你能说……"。
- **顶部**：连续天数 🔥、XP ⭐、每日目标圆环（10 / 20 / 30 / 50 XP 四档可选）。
- **奖励**：完成单元、通过阶段考试有动画和徽章；"我会说了"收藏页，存着每课自己说得最好的一句录音（只存在手机上）。
- 不做商店、宝石、排行榜。

## 7. 配图

- **只给能画的词配图**：物品、食物、动物、动作、地点、人物、天气、交通等；抽象词不硬配，靠例句和讲解。能配图的大约占三到四成，T19 先做工具统计准确数量。
- **同一个意思四门课共用一张图**：词条加一个可选的"概念"字段，词条 id 不变。
- **来源（店主在 T16 选）**：
  - **A. 免费图标库（建议先用）**：例如 Microsoft Fluent Emoji（MIT 许可，可商用）或 OpenMoji（CC BY-SA，要署名）。不花钱、马上能做。草图 ② 的 🙏 就是这种效果。
  - **B. AI 生成插画**：更好看；要店主开通图片生成服务（密钥只填进环境设置）并承担费用，每张要人工抽查。
  - 可以先 A 后 B。角色头像和场景图同理。

## 9. 对现有东西的影响

- **内容**：已有课一律不重写。T22 给 A、B 阶段改写讲解（一句结论 + 例句 + 泰语对比）、每课加一句场景和角色扮演提示（母语层）、A 阶段每单元加 1 篇短读物（新 `-r` 课号）、加汉字部首 / 假名 / 韩文字母的认读讲解；新句子补配音。
- **服务器**：口语题变多，免费额度按 §8 第 2 条调；发音打分接口不变。
- **进度和复习**：格式不变，旧进度照常能用；练习课、测验是引擎现生成的，换题型不影响存档。
- **e2e**：课程地图、上课页面、完成页的检查要按新界面改写；口语题在测试里用"现在不方便说话"跳过或用假录音。
- **其他母语**：界面文字的 key 照旧以 `content/l1/th/ui.json` 为准；讲解卡、配图、角色不写死语言。
